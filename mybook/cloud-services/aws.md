# Amazon Web Services (AWS)

```{admonition} Quick Facts
:class: tip
- **Type:** Public cloud platform
- **Use cases:** Compute, storage, databases, networking, ML/AI, serverless, DevOps
- **Key services:** EC2, S3, Lambda, RDS, IAM, VPC, CloudWatch, ECS, Route 53
- **CLI tool:** `aws` (AWS CLI v2)
- **Free tier:** 12 months free + always-free services available
```
